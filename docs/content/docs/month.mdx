The value is the browser's own month string, such as `2026-11`. `""` is empty. With `range`, a span of months: `<DatePicker type="month" range value={["2026-01", "2026-06"]} onChange={setRange} />`.

## Props

| Prop | Type | What it does |
| --- | --- | --- |
| `min`, `max` | `string` | Limits in the type's format. A limit in another format is ignored. |
| `presets` | `{ label, value }[]` | Buttons under the calendar; `value` may be a function. |
| `presentation` | `"popover" \| "dialog" \| "auto"` | How the calendar opens; `auto` is a dialog under 768 px wide. |
| `popoverProps`, `dialogProps` | object | Open state (`open`, `defaultOpen`, `onOpenChange`) and the content props of the popover or dialog. |
| `calendarProps` | object | Props passed to react-day-picker: `locale`, `startMonth` and `endMonth` only. |

More options (limits, presets, labels, the dialog) are in the <StorybookLink>Storybook</StorybookLink>.
